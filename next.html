开放

你的媒体库，你的模型。

开源

NipaPlay 和梨花用到的工具全部开源，代码在 GitHub 的 AimesSoft/NipaPlay-Reload。

模型由你选择

填入自己的接口地址和密钥。官方服务、中转和自建的服务都可以。

数据在你自己的设备上

媒体库、梨花的记忆和设置都保存在本机，设备之间直接连接。

全平台

macOS、Windows、Linux、iPhone、iPad，以及无界面的 Linux 服务器。
