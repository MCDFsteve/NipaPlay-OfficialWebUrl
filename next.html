架构

一层一层，
看她怎么工作。

  1. 01

    能力层

    NipaPlay 的每个功能都注册为一项能力：播放、检索、下载、元数据、弹幕、设备管理，共 38 类 330 项。界面和智能体调用同一套能力，界面能做的，梨花都能做。

  2. 02

    服务层

    能力由服务层执行：Erika 播放内核、媒体库、下载器、弹幕、字幕和组网。服务层不依赖智能体；任务在后台执行，关闭对话不会中断。

  3. 03

    智能体与 Harness

    梨花运行在 DeepSeek Harness 上，也可换用 Codex，模型接入你自己的 API。她的指令、记忆、工具和钩子在最底层的 Harness 里，一个 Git 仓库。

Harness

她的家，
一个 Git 仓库。

  1. 01

    写给她的目标和规矩

    AGENTS.md 写着她是谁、为谁做事、什么算办好、什么必须先问你。每次开工，她先读这里。

  2. 02

    她记下的事

    你的偏好、她学到的做法、某部作品的笔记，都在 memory/ 里，每条带日期和出处。用之前先核对现在的状态，密码和令牌不进记忆。

  3. 03

    她自己写的工具

    tools/ 里是找资源、取弹幕、查接口的脚本，她可以改，也照着任务写新的；hooks/ 里的程序在下载完成、开始播放这些时刻自动运行。

  4. 04

    每一次改动都有记录

    她的每次修改都是一次提交。改了什么、为什么改，你都看得到，不满意就撤回。
